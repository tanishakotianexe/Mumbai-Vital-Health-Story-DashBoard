# Mumbai Vital Health Story DashBoard

Analyzing Mumbai's vital health statistics (2015–2020) using Power BI and Python.





Project Overview

This repository contains the complete first-semester project for my M.Sc. in Data Science program. The project investigates Mumbai's vital public health statistics from 2015 to 2020, utilizing official data records from the Municipal Corporation of Greater Mumbai (MCGM). 



The analysis evaluates long-term urban demographic shifts, natality contractions, general mortality surges during the COVID-19 pandemic, and pediatric/maternal healthcare outcomes through an advanced multi-page interactive Power BI Dashboard and exploratory data analysis.
